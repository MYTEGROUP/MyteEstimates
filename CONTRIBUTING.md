# Contributing to MYTE Seed

This repository is intentionally a seed: small, auditable, and runnable.

## Principles
- Keep the pipeline inspectable and artifact-driven.
- Prefer clarity over abstraction.
- Avoid adding platform features (governance, multi-tenant auth, etc.); those are out of scope here.
- Preserve artifact schemas when possible (breaking changes should be explicit).

## How to contribute
1) Fork the repo
2) Create a feature branch: `git checkout -b feat/your-change`
3) Keep PRs small and scoped
4) Explain:
   - What changed
   - Why it matters
   - How to test it
5) Open a PR

## What we love
- Improvements to artifact stability and readability
- Better prompts and tighter schemas
- Better local-first developer ergonomics
- Documentation improvements
